# Documentation Assets

Place images referenced by the documentation here.

| File | Used by | Suggested size |
| --- | --- | --- |
| `banner.png` | `README.md` header banner | 1280×320 (2× for retina) |
| `screenshot-start.png` | `README.md` Screenshots section | actual terminal capture |
| `screenshot-search.png` | `README.md` Demo section | actual terminal capture |

Guidelines:

- Prefer PNG for screenshots, SVG for diagrams/logos.
- Keep individual files under ~500 KB where possible.
- Capture terminal output at a readable font size on a clean theme.
- For animated demos, record with [asciinema](https://asciinema.org/) and embed
  the player link rather than committing large GIFs.
